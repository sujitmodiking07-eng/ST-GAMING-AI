# ST GAMING AI

A responsive gaming tips dashboard built with React, TypeScript, and Vite.

## Run locally
1. Install Node.js.
2. Run `npm install`
3. Run `npm run dev`

## Build website
`npm run build` creates the website in `dist/`.

## Android
Install Capacitor CLI, then run:
- `npx cap add android`
- `npm run build`
- `npx cap sync android`
- `npx cap open android`

Note: The included assistant is a lightweight offline FAQ helper, not a generative AI service. An AI API/backend must be connected for generative responses.
